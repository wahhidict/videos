# 📘 دليل المستخدم — موشن ستوديو AI برو

أهلًا بك! هذا الدليل يشرح كل ما تحتاجه لإنشاء فيديو احترافي — بدون أي خبرة تقنية.

## ١. لوحة التحكم (الرئيسية)

عند فتح التطبيق ترى ٦ أزرار فقط:

| الزر | متى تستخدمه |
|---|---|
| **إنشاء فيديو جديد** | لديك فكرة وتريد البدء من الصفر |
| **تحويل نص إلى فيديو** | لديك نص جاهز (سكربت/مقال) |
| **إنشاء فيديو تعليمي** | شرح درس أو مفهوم |
| **إنشاء فيديو إعلاني** | إعلان منتج أو خدمة |
| **استخدام قالب جاهز** | تختار من مكتبة القوالب مباشرة |
| **مشاريعي السابقة** | فتح أو حذف أو تكرار مشروع محفوظ |

## ٢. المعالج المُوجَّه (٦ خطوات)

1. **الفكرة**: اكتب موضوع الفيديو أو الصقه كنص كامل. (زر «استخدم الذكاء الاصطناعي المحلي» يظهر فقط إن كان Ollama مثبّتًا، وإلا يستخدم التطبيق توليدًا عربيًا داخليًا فوريًا).
2. **نوع الفيديو**: تعليمي، وثائقي، قصصي، إعلاني، موشن جرافيك، يوتيوب، ريلز، مالي، تداول.
3. **المدة**: ٣٠ ثانية، دقيقة، ٣، ٥، ١٠، ١٥ دقيقة أو «مدة مخصصة».
4. **النمط البصري**: سينمائي، احترافي، ثلاثي الأبعاد، إنفوغرافيك، بسيط وأنيق، تقني، وثائقي.
5. **الصوت**: رجالي، نسائي (عند توفره)، بدون صوت، أو رفع تسجيل صوتي خاص بجهازك.
6. اضغط **«إنشاء الفيديو»**.

يقوم التطبيق تلقائيًا بـ: كتابة السكربت → تقسيمه إلى مشاهد → بناء الرسوم والحركات → إعداد التعليق الصوتي → توليد الترجمة، ثم يعرض **لوحة القصص (Storyboard)**.

## ٣. لوحة القصص

قبل الترميز النهائي ترى بطاقة لكل مشهد مع صورة مصغّرة حية:
- عدّل نص السكربت داخل البطاقة مباشرة.
- عدّل مدة المشهد بالثواني.
- كرّر، احذف، أو أعد توليد المشهد.
- اضغط أي بطاقة لفتح المحرر من هذا المشهد.

## ٤. المحرر

| المنطقة | المحتوى |
|---|---|
| **يسار** | المشاهد / القوالب / الصور / النصوص / الصوت / الترجمة |
| **الوسط** | معاينة الفيديو (تشغيل، إيقاف، تنقّل) |
| **الأسفل** | خط الزمن مع المشاهد والدقيقة |
| **يمين** | خصائص العنصر المحدد (نص، لون، حركة، حجم...) |

### إجراءات سريعة بالعربية
«تغيير النص» • «تغيير الصورة» • «تغيير اللون» • «إضافة حركة» • «تغيير الصوت» • «تعديل مدة المشهد» • «حذف المشهد» • «تكرار المشهد» • «معاينة الفيديو» • «تصدير الفيديو»

«الوضع المتقدم» يفتح تحكمًا إضافيًا (الإطارات المفتاحية، الإظهار والتخفيف، الكاميرا) — وهو مخفي افتراضيًا كي لا يُربك المستخدم الجديد.

### التراجع والإعادة والأوامر بلغة طبيعية

- **تراجع / إعادة**: زاران أعلى المحرر — كل تعديل يدوي أو أمر طبيعي قابل للرجوع، حتى 60 خطوة، ويُفرَغ سجل الإعادة عندما تبدأ تعديلاً جديداً.
- **شريط الأوامر**: اكتب بالعربية وأضغط Enter، مثال:
  - «غيّر لون الخلفية إلى الأزرق الداكن» · «اجعل المشهد الثاني سينمائياً» · «اجعل التعليق الصوتي أبطأ قليلاً» · «اخفض الموسيقى أثناء الكلام» · «اختصر الفيديو إلى دقيقة» · «اجعل الانتقالات أكثر نعومة» · «احذف هذا المشهد».
- الأوامر التي تغيّر أجزاءً كثيرة (حذف مشهد، اختصار الفيديو) تطلب تأكيدك قبل التنفيذ.

## ٥. الصوت والترجمة

- **مكتبة الصوت**: مؤثرات وموسيقى مُولّدة محليًا — معاينة ثم «إضافة». لا يوجد أي ملف محمي بحقوق.
- **تسجيل**: سجّل من الميكروفون مباشرة.
- **نص إلى كلام**: يستخدم Piper على سطح المكتب بعد الإعداد، ومعاينة صوت المتصفح كاحتياط.
- **الترجمة**: توليد تلقائي من مشاهد المشروع، استيراد/تصدير SRT، تحرير يدوي لكل سطر، تظليل الكلمات، التحكم في الحجم والموضع واللون.
- رفع MP3/WAV من جهازك مدعوم مع أداة قص ومستوى صوت وتلاشي.

## ٦. التصدير

1. اضغط **«تصدير الفيديو»**.
2. اختر الدقة (٧٢٠p/١٠٨٠p/١٤٤٠p/٤K حسب أداء جهازك) وعدد الإطارات (٢٤/٢٥/٣٠/٦٠).
3. راقب التقدّم الحقيقي (يعكس الإطارات المُرمّزة فعلًا، لا محاكاة).
4. يمكنك الإلغاء أو إعادة المحاولة عند الخطأ، وقراءة السجلات العربية.
5. يُحفظ الملف تلقائيًا ويظهر معاينة + زر تصدير ملف الترجمة SRT.

في الويب يعتمد الامتداد (WebM أو MP4) على قدرات متصفحك؛ وعلى ويندوز يُنتج MP4 دائمًا عبر FFmpeg ويمكنك اختيار مجلد الحفظ.

## ٧. المشاريع

- **حفظ تلقائي** أثناء العمل — لا تفقد شيئًا لو أُغلق المتصفح.
- من «مشاريعي السابقة»: فتح، تكرار، حذف، **تصدير ملف JSON محمول** واستيراده على أي جهاز.
- لا حساب، لا تسجيل دخول، ولا سحابة إلا إذا فعّلت التزامن الاختياري بنفسك.

## ٨. نصائح للأجهزة العادية

- للمعاينة استخدم «جودة المعاينة» المنخفضة على الأجهزة الضعيفة.
- معاينة ٧٢٠p تكفي غالبًا ثم صدّر بدقة عالية.
- أثناء التصدير تظل الواجهة تعمل كالمعتاد — الترميز لا يجمد التطبيق.
