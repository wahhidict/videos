# خطة العمل — MOTION STUDIO AI PRO (بروتوكول المهمة الواحدة)

القيود الصارمة:
- الجهاز: 8GB RAM بلا GPU — سقف التصدير 1080p30 (و1080×1920 عمودي)، لا 4K، لا توليد صور محلي.
- Ollama: نموذج 3B Q4 فقط، ويُفرَّغ من الذاكرة بعد التوليد.
- مجاني 100% — المسموح حصراً: Pexels API (مفتاح مجاني، 200/ساعة و20000/شهر)،
  Pixabay API (مفتاح مجاني، 100/دقيقة، cache إلزامي 24h، صور افتراضية ≤1280px)،
  Pollinations Classic بلا مفتاح (صورة كل ≥45ث لكل IP، سقف 768×768، خلفيات/مفاهيم فقط،
  احترام Retry-After عند 402، seed ثابت)، Groq (مفتاح مجاني بلا بطاقة، 30/دقيقة،
  1000/يوم، 8000 توكن/دقيقة — تقسيم الطلبات الطويلة)، OpenRouter :free (احتياط،
  20/دقيقة و50/يوم)، Ollama محلي + Piper TTS للأوفلاين.
- ممنوع: Mistral API، أي mock أو محاكاة أو progress وهمي، كسر الاختبارات الموجودة
  (188 core + web + e2e).

## المهام — بالترتيب، المهمة = جلسة واحدة

- **M1 بوابة جودة**: سكربت ffprobe بعد كل تصدير (مدة ±0.2s، وجود audio stream، دقة)
  + حفظ 5 إطارات PNG + قياس loudness. فشل تلقائي إذا صامت أو مدة غلط.
- **M2 صوت MediaRecorder**: AudioContext حي → MediaStreamAudioDestinationNode →
  دمج audio track مع canvas.captureStream في MediaStream واحد.
  القبول: ffprobe يُظهر صوتاً مسموعاً فعلياً.
- **M3 Asset Gateway**: cache قرص (مفتاح hash الطلب، سقف 2GB LRU، احترام 24h لـPixabay)،
  طابور rate-limit + Retry-After، metadata تراخيص لكل أصل،
  fallback: stock → توليد → Openverse/Wikimedia → أشكال.
  القبول: إعادة تصدير offline من الـcache.
- **M4 Pexels+Pixabay**: بحث كلمات المشهد، تنزيل ≤1920px، قصّ فيديو حسب مدة المشهد،
  Ken Burns للصور، تنزيلات متزامنة ≤2.
  القبول: فيديو 30s فيه b-roll حقيقي بلا أي مفتاح مدفوع.
- **M5 Pollinations Classic**: طابور 45s + seed ثابت + خلفيات مع gradient overlay.
  القبول: مشهد مفاهيمي يأخذ خلفية مولّدة بلا ضرب 402.
- **M6 محرك تصميم**: توكنز (6 لوحات ألوان، مقياس خط Cairo/Tajawal، easing موحّد،
  انتقالات 250–350ms) + 6 قوالب مشاهد (hook/مشكلة/حل/إحصاء/اقتباس/CTA +
  intro/outro/lower-third) + 3 صيغ (16:9، 9:16، 1:1) بإعادة ترتيب العناصر لا قصّها.
  القبول: نفس السيناريو بـ3 صيغ، كل وحدة مصمّمة عمداً.
- **M7 الكاتب**: adapter لـGroq ثم OpenRouter :free عبر ProviderGateway الموجود،
  المفتاح بـMemorySecretStore فقط، برومبت مخرج عربي يُخرج DirectedPlan منظم،
  offline: Ollama 3B ثم القوالب المحسّنة.
  القبول: 6 مشاهد متماسكة، وتبديل المزوّد أو قطع الإنترنت لا يكسر التصدير.
- **M8 موسيقى وSFX من Pixabay** (الإجرائي يبقى fallback) + ducking الموجود +
  loudness نهائي −14 LUFS. القبول: موسيقى حقيقية وصوت موزون.
- **M9 offline**: حزمة أول تشغيل (تنزيل مكتبة أساسية ضمن التراخيص إلى الـcache)
  — أصول CC0 صغيرة مدمجة بالمثبّت.
  القبول: تصدير كامل والإنترنت مقفول بعد أول تشغيل.

## قواعد العمل

1. كل جلسة = مهمة وحدة فقط. لا مهمة جديدة قبل قبول الحالية بمعيارها.
2. قراءة الضروري فقط للملفات؛ لا لصق ملفات كاملة في الردود. الردود ≤10 أسطر:
   ماذا تغيّر + نتيجة الاختبار + الحالة.
3. اختبارات مستهدفة فقط (vitest للمسار المعني) + e2e مرة عند نهاية المهمة.
4. بعد كل خطوة: تحديث docs/AGENT_STATE.md + commit برسالة "M#: وصف قصير".
5. نهاية المهمة: تصدير فيديو عينة 20–30s، تشغيل بوابة الجودة، عرض ملخص ffprobe،
   ثم التوقف بعبارة "DONE M# — التالي M#".
6. الاستئناف بعد انقطاع السياق = قراءة docs/AGENT_STATE.md فقط.
7. ممنوع ادعاء نجاح بلا دليل (اختبار/ffprobe/إطار محفوظ).
8. قرار غير محسوم = سؤال واحد محدد ثم التوقف.
