# 🤖 إعداد الذكاء الاصطناعي المحلي

هذا الدليل لمن يريد تشغيل وحدات الذكاء الاصطناعي **المحلية الاختيارية**.

> كل هذه الوحدات اختيارية ١٠٠٪. بدونها يعمل التطبيق كاملًا بقوالب جاهزة وتوليد عربي داخلي ولا يحتاج إنترنت ولا نموذجات ولا خدمات مدفوعة.

## ١. Ollama — لتوليد وتحسين النصوص

**الفائدة**: كتابة سكربتات عربية أذكى بناءً على فكرتك.

| البند | القيمة |
|---|---|
| الحجم التقريبي | ٢–٥ GB حسب النموذج |
| التخزين المطلوب | ٥ GB فارغة على الأقل |
| العتاد | ٨ GB ذاكرة RAM (١٦ GB مفضلة) |

**خطوات التثبيت (ويندوز):**
1. حمّل Ollama من `https://ollama.com/download/windows` ونصّبه.
2. افتح موجه الأوامر ونفّذ: `ollama pull qwen2.5:3b`
3. في التطبيق: الإعدادات ← إعداد الذكاء الاصطناعي المحلي ← Ollama ← «فحص الاتصال».

يتصل التطبيق بالخادم المحلي `http://127.0.0.1:11434` — لا تنتقل أي بيانات إلى الإنترنت.

## ٢. Piper — التحويل النصي إلى صوت عربي

**الفائدة**: تعليق صوتي عربي حقيقي بدون خدمات مدفوعة.

| البند | القيمة |
|---|---|
| الحجم التقريبي | ٥٠–١٠٠ MB لكل صوت |
| التخزين المطلوب | ٥٠٠ MB فارغة |
| العتاد | يعمل على أي جهاز حديث |

**خطوات التثبيت:**
1. حمّل Piper من صفحة الإصدارات على GitHub (`rhasspy/piper`).
2. حمّل صوتًا عربيًا (نموذج `.onnx` مع ملف الإعدادات `.json`).
3. في التطبيق: الإعدادات ← Piper ← حدّد مسار مجلد Piper وملف الصوت ← «اختبار الصوت».

على سطح المكتب يشغّل التطبيق أوامر Piper محليًا ويعيد ملف WAV.

## ٣. Whisper — التفريغ الصوتي للترجمة

**الفائدة**: تحويل التسجيل الصوتي أو التعليق إلى ترجمة عربية/إنجليزية تلقائيًا.

| البند | القيمة |
|---|---|
| الحجم التقريبي | ٧٥ MB (base) – ١.٥ GB (large) |
| التخزين المطلوب | ٢ GB فارغة |
| العتاد | ٤ GB ذاكرة RAM كحد أدنى |

**خطوات التثبيت:**
1. استخدم نسخة `whisper.cpp` (الملف التنفيذي `whisper-cli`).
2. حمّل نموذج `ggml` (مثل `ggml-base-q5_1.bin`).
3. في التطبيق: الإعدادات ← Whisper ← حدّد مسار البرنامج والنموذج ← «اختبار التفريغ».

صوتك يعالَج على جهازك فقط ولا يُرسل لأي مكان.

## ٤. توليد الصور محليًا (اختياري متقدم)

يدعم التطبيق تكاملًا اختياريًا مع مولّدات صور محلية (مثل Stable Diffusion عبر ComfyUI أو Automatic1111) إن كانت أجهزتك تحتوي معالج رسومي قوي (٦ GB ذاكرة على الأقل). الوحدة معطَّلة افتراضيًا — وبدون صور مولّدة يعمل التطبيق بالأشكال والأيقونات SVG والعناصر الرسومية الجاهزة.

## ٥. ما الذي يحدث بدون أي ذكاء اصطناعي؟

- السكربتات تُولَّد بنيويًا بالعربية (قوالب لغوية حسب نوع الفيديو والمدة).
- المشاهد والحركات تُبنى تلقائيًا — الإنفوغرافيك والمخططات والحركات الجاهزة تعمل بالكامل.
- الصوت: «بدون صوت» أو رفع تسجيل صوتي خاص بك.
- الترجمة: تُولَّد تلقائيًا من مشاهد المشروع بتوقيتات حقيقية ويمكن تحريرها يدويًا.
