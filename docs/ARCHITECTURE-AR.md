# المعمارية التقنية — MOTION STUDIO AI PRO

> وثيقة حيّة توثّق البنية الفعلية للكود حتى commit المرحلة ح. كل وحدة مذكورة هنا موجودة ومُختبَرة في المستودع.

## نظرة عامة

Monorepo بثلاث وحدات:

| المسار | الدور | التقنيات |
|---|---|---|
| `packages/core` | منطق الإنتاج الخالص (بلا DOM ولا شبكة) | TypeScript + vitest |
| `apps/web` | واجهة الويب + التصدير في المتصفح | React 18 + Vite + WebCodecs |
| `apps/desktop` | نسخة ويندوز | Tauri 2 + Rust |

مسارات الحزم: `@msaipro/core` يُستورد من الواجهتين مباشرة.

## خط الإنتاج المركزي: AI Director

```
فكرة/سكريبت المستخدم
   ↓ directedProject (director.ts)
   ├─ تحليل النص: نوع المحتوى، الجمهور، المنصة، اللكنة، الرسالة
   ├─ بنية سردية: hook → setup → middle → cta
   ├─ دليل الأسلوب البصري (Style Guide) لكل المشاهد — استمرارية بصرية
   └─ خطة بصرية لكل مشهد (لقطة/زوايا/حركة/إضاءة/انتقال)
   ↓ buildDocFromPlan (builder.ts)
ProjectDoc (مشاهد + طبقات + خلفيات + صوت)
```

- **وضع الفكرة**: `planStoryboard` يولّد سيناريو عربياً منظّماً حسب النوع والمدة، ويمنع تكرار الجُمَل، مع حارس anti‑leak يمنع وصول تعليمات المستخدم («أنشئ فيديو…», «اجعل…») إلى النص الظاهر أو المنطوق.
- **وضع السكريبت الملصق**: `planStoryboardFromScript` يحافظ على جُمَل المستخدم **حرفياً** (تقسيم الجمل الطويلة عند الفواصل فقط دون أي إعادة صياغة).
- **احترام المدة**: عدد المشاهد ومدد تُقاس على الهدف (30ث ≈ 4–6 مشاهد، 60ث ≈ 7، إلخ) ويبقي المجمع المدة قريبة من المطلوب — متحقَّق منه في e2e لكل سيناريو (A–F).

## واجهة الويب

- `store/appState.tsx`: مصدر الحقيقة الوحيد. كل تعديل عبر `updateDoc` يستنسخ المستند (بلا تحوير) **ويدفع snapshot إلى `EditHistory`** قبل التطبيق → أي تعديل (يدوي أو بأمر طبيعي) قابل للتراجع. أوامر الحذف/الاختصار المدمّرة تمرّ عبر `runNaturalCommand` ثم `confirmNaturalCommand` بعد تأكيد المستخدم.
- `views/Editor.tsx`: شريط أعلى فيه تراجع/إعادة وشريط أوامر عربي طبيعي (Enter ينفّذ).
- `views/Storyboard.tsx`: بطاقة لكل مشهد (رقم، عنوان، نص ظاهر، معاينة canvas، مدة، حالة الصوت) مع إعادة توليد مشهد واحد أو السيناريو كاملاً.
- `export/`: `presets.ts` (نسبة 16:9/9:16/1:1/4:5، دقّات 720p→4K بأبعاد زوجية، bitrate مشتق، مرشّح دقّات، ترشيح ترميز H.264/H.265/VP9، فحص نتيجة التصدير) و`exporter.ts` (WebCodecs→MP4 عبر mp4-muxer، بديل MediaRecorder→WebM عند غياب الدعم).
- `components/ToolsManager.tsx`: مدير التنزيل للأدوات الاختيارية (Piper/Whisper/FFmpeg) — عرض الحجم، موافقة قبل التحميل، تحقق SHA256 قبل فك الضغط، معالجة فشل الشبكة/الإلغاء/إعادة المحاولة.
- العربية أولاً: RTL في كامل الواجهة، خط Cairo، `dir=rtl` على `<html>`.
- الحفظ: localStorage لقائمة المشاريع + الحفظ التلقائي المؤجّل 900ms لكل مشروع، HTTP-free بالكامل افتراضياً.

## نسخة سطح المكتب (Tauri 2)

- `tauri.conf.json`: `frontendDist` يشير إلى مجلد بناء الواجهة الصحيح (انظر قرار «asset not found» في CHANGELOG).
- أوامر Rust: تنزيل الأدوات مع SHA256، تشغيل Piper TTS محلياً، تفادي تنفيذ أي شيء غير موقَّع (`src-tauri/src/*`).
- بناء Windows عبر GitHub Actions: خطوة بناء الواجهة **قبل** tauri-action مع حارس يرفض التغليف إن غاب `dist/index.html`.

## قواعد الامتثال المشتركة

- لا مفاتيح API في الكود؛ المفاتيح في المتصفح بذاكرته فقط (لا LocalStorage)، وفي الويندوز عبر أمر Rust للخزّن الآمن.
- لا نداء خدمة مدفوعة دون `confirmPaid` صريح من المستخدم.
- سقف تسريع الصوت 1.25x — التخفيف يكون بتقصير الجمل وإعادة التوزيع.
- ذروة الصوت ≤ −1 dBFS.
- لا نسبة جودة وهمية: Quality Controller يخرج قائمة مشاكل وإصلاحات محددة فقط.
