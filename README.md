# 🎬 موشن ستوديو AI برو — الإصدار ٣

**MOTION STUDIO AI PRO — V3 — SIMPLE ARABIC FIRST — FREE FOREVER EDITION**

تطبيق موشن جرافيك احترافي بالعربية، مجاني للأبد، يعمل محليًا بدون أي خدمات مدفوعة أو اشتراكات أو حسابات إلزامية.

- **واجهة عربية كاملة** (RTL) بخطوط Cairo وTajawal — مع خيار إنجليزي اختياري.
- **مجاني للأبد**: كل الوظائف الأساسية تعمل بدون مفاتيح API مدفوعة أو بطاقة ائتمان.
- **محلي أولًا**: المشاريع والأصول والعرض تُحفظ وتُنفَّذ على جهازك.
- **ويب + ويندوز**: نفس الواجهة في المتصفح، وتطبيق سطح مكتب Tauri مثبّت فعليًا.

---

## ✨ المزايا

### لوحة التحكم (٦ أزرار فقط)
إنشاء فيديو جديد • تحويل نص إلى فيديو • إنشاء فيديو تعليمي • إنشاء فيديو إعلاني • استخدام قالب جاهز • مشاريعي السابقة

### معالج مُوجَّه من ٦ خطوات
1. اكتب الفكرة أو النص.
2. اختر نوع الفيديو (تعليمي، وثائقي، قصصي، إعلاني، موشن جرافيك، يوتيوب، ريلز، مالي، تداول).
3. اختر المدة (٣٠ ثانية → ١٥ دقيقة أو مخصصة).
4. اختر النمط البصري (سينمائي، احترافي، ثلاثي الأبعاد، إنفوغرافيك، بسيط، تقني، وثائقي).
5. اختر الصوت (رجالي/نسائي/بدون/رفع تسجيل).
6. «إنشاء الفيديو» → لوحة قصصية للمراجعة قبل التصدير النهائي.

### محرر بسيط
يسار: المشاهد، القوالب، الصور، النصوص، الصوت • الوسط: معاينة الفيديو • الأسفل: خط الزمن • يمين: خصائص العنصر. التحكم المتقدم مخفي حتى تطلبه.

### محرك حركة مجاني
طباعة متحركة، انتقالات، أشكال، خلفيات متحركة، SVG، مخططات، تكبير وتحريك، إطفاء/تحجيم/دوران، أقنعة، جزيئات، حركة كاميرا، إطارات مفتاحية، تخفيف حركة (easing) وباقات حركة جاهزة — أنت لا تصمّم الحركة يدويًا أبدًا.

### استوديو الصوت
تحويل نص إلى كلام محلي (Piper)، تسجيلات الميكروفون، مكتبة مؤثرات وموسيقى مُولّدة محليًا (مكافئة CC0 — لا موسيقى محمية بحقوق)، قص، مستوى صوت، تلاشي، تزامن، مسارات متعددة، MP3/WAV.

### محرك الترجمة
عربي/إنجليزي، تفريغ صوتي محلي (Whisper) عند الإعداد، تحرير يدوي، تظليل الكلمات، تصدير SRT، وعرض RTL الصحيح.

### العرض المحلي
WebCodecs في المتصفح وFFmpeg على سطح المكتب. دقة ٧٢٠p–٤K، إطارات ٢٤/٢٥/٣٠/٦٠، تقدّم حقيقي (لا محاكاة)، إلغاء وإعادة محاولة، سجلات عربية، ومُجلّد تصدير مختار.

## 🚀 التشغيل السريع

```bash
npm install
npm run dev          # واجهة الويب العربية
```

### أوامر التحقق

| الأمر | ما يفعله |
|---|---|
| `npm run typecheck` | فحص الأنواع في كل الحزم |
| `npm test` | اختبارات المحرك + واجهة المستخدم |
| `npm run e2e:render` | توليد **فيديو حقيقي** من البداية للنهاية |
| `npm run e2e:browser` | اختبار المتصفح الكامل (يحتاج تبعيات متصفح) |
| `npm run build` | بناء واجهة الويب |
| `npm run desktop:build` | بناء مُثبّت ويندوز (NSIS) |

---

## 🖥️ نسخة ويندوز (Tauri)

```bash
npm run desktop:build
```

ينتج مُثبّتًا حقيقيًا في `apps/desktop/src-tauri/target/release/bundle/`. التطبيق يعمل بدون متصفح، يفتح محليًا، يحفظ المشاريع على القرص، ويصيّر الفيديو محليًا حتى بدون إنترنت.

### الذكاء الاصطناعي المحلي (اختياري بالكامل)

من «الإعدادات ← إعداد الذكاء الاصطناعي المحلي» يمكنك توصيل:
- **Ollama** لإكمال النصوص (`ollama pull qwen2.5:3b`)
- **Piper** للتحويل النصي إلى صوت عربي
- **Whisper** للتفريغ الصوتي للترجمة

لا شيء منها مطلوب — بدونها يعمل التطبيق بتوليد نصوص عربية داخلي وقوالب جاهزة، ولا يُنزَّل أي نموذج كبير تلقائيًا أبدًا.

## 📦 بنية المشروع

```
packages/core      محرك المونتاج (بدون تبعيات وقت تشغيل — 18 اختبار vitest)
apps/web           واجهة React العربية (Vite + TypeScript) والتصدير عبر WebCodecs
apps/desktop       غلاف Tauri 2 (NSIS + أوامر Rust: حفظ الملف، ترميز MP4، Piper، Whisper)
e2e                اختبار توليد فيديو حقيقي (@napi-rs/canvas + FFmpeg)
docs               أدلة المستخدم بالعربية
```

## 📄 الرخص والأصول
- الخطوط: **Cairo** و**Tajawal** عبر @fontsource (رخصة SIL OFL).
- المؤثرات والموسيقى: مُولّدة برمجيًا داخل التطبيق (مكافئة CC0) — لا ملفات محمية بحقوق.
- الحزم المفتوحة: React، Vite، TypeScript، Tauri 2، mp4-muxer، @napi-rs/canvas، Playwright.
